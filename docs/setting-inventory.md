# Extended / Survival setting inventory

Audited against the installed Starsector 0.98.5a-RC7 on 2026-11-16. This inventory includes every `ext_` key in the shipped settings file. Defaults are Extended defaults, not inferred normal-mode values.

Status: **live** = dynamic consumer inspected; **future** = subsequent stock, offers or rolls only; **creation** = source consumer found but limited to creation to avoid claiming retroactive changes; **unverified** = setting exists but its effect/timing has not been established from the supplied source; **unused** = explicitly marked unused; **identifier** = not numeric. Unsupported controls are omitted from the menu; unchanged defaults are hidden unless previously customized. Source inspection is not an in-game playtest.

Array order: frigate, destroyer, cruiser, capital.
